### 🌟 Destaques do Projeto Portfólio

<p align="left">
  Este portfólio vai além de uma simples página de links: é uma <b>aplicação web rica e interativa</b> construída com foco em design moderno, performance e gamificação:
</p>

- 🎨 **Design Glassmorphism Dark:** Fundo translúcido com efeito de desfoque (*backdrop-filter*), partículas dinâmicas e tipografia responsiva.
- ✍️ **Canvas de Desenho Livre:** Os visitantes podem desenhar livremente pela tela com persistência de traço e botão inteligente para limpar a tela (`🧹 Limpar Tela`).
- 🎮 **Easter Egg Gamificado — "Pegue o Pombo":**
  - Trilha sonora oficial em MP3 com controle de volume e modo silencioso/chill.
  - Sistema de 3 vidas com barra de tempo e física de voo realista com esquivas.
  - **Aceleração progressiva contínua** inspirada na curva de velocidade do *Jogo do Dinossauro do Google*.
  - **Tabela de Recordes (Leaderboard):** Salva o nome do jogador no ranking local, atualiza recordes e avisa quando a pontuação não foi superada.
- ⚡ **Alta Performance:** Otimizado para Core Web Vitals, pré-carregamento de fontes e 100% responsivo para mobile e desktop.

### 🚀 Como Executar Localmente / Getting Started

Para clonar e testar o projeto em sua máquina local:

```bash
# 1. Clone este repositório
git clone https://github.com/luiiz2/Meu-Portifolio.git

# 2. Acesse a pasta do projeto
cd Meu-Portifolio

# 3. Inicie um servidor local (exemplo com Python):
python -m http.server 3000

# 4. Abra o seu navegador e acesse:
# http://localhost:3000
```
